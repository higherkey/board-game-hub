How to play

Goal

The Crew must guess the secret word before time runs out. One player is secretly the J, trying to lead everyone astray.

Roles

Main Computer
Knows the word. Answers the Crew's questions with a limited set of tokens: yes, no, maybe and so on.
The J
Knows the word. Wastes time and steers questions the wrong way. Wins if the word stays hidden.
The Empath
Knows the word. Guides the Crew without letting the J spot them.
Crew
Doesn't know the word. Asks clever questions to narrow it down.

How it ends

Word guessed: the J gets one last chance to win by naming the Empath.

Time runs out: the Crew votes on who the J is. Catch them and the Crew wins; miss and the J wins.
